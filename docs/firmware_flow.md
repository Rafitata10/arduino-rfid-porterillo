```mermaid
flowchart TD

START[Boot Arduino]

INITSD[Initialize SD with SoftSPI]

CHECKSD{SD OK?}

LOADSD[Load UIDs.txt]
LOADDEFAULT[Load Default UID List]

STARTRFID[Initialize RC522]

WAITCARD[Wait for RFID Tag]

READUID[Read UID]

CHECKAUTH{UID Authorized?}

ACCESSOK[Blue LED Blink]
ACCESSDENY[Red LED Blink]

START --> INITSD
INITSD --> CHECKSD

CHECKSD -->|Yes| LOADSD
CHECKSD -->|No| LOADDEFAULT

LOADSD --> STARTRFID
LOADDEFAULT --> STARTRFID

STARTRFID --> WAITCARD
WAITCARD --> READUID
READUID --> CHECKAUTH

CHECKAUTH -->|Yes| ACCESSOK
CHECKAUTH -->|No| ACCESSDENY

ACCESSOK --> WAITCARD
ACCESSDENY --> WAITCARD
